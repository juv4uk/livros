## Конкретні місця для звіряння

| Вірш | Санскритський орієнтир | Питання до чинної української редакції | Запропонована редакторська дія |
| --- | --- | --- | --- |
| **1.2** | `kṣamā / ārjava / dayā / toṣa / satya` | У чинному ланцюжку «терпимість, щирість, співчуття, простота й чесність» не виділено `toṣa` («вдоволеність»). «Простота» і «щирість» можуть по-різному передавати `ārjava`, але не компенсують пропущеного поняття. | Перевірити відповідність **усіх п'яти** чеснот; окремо пояснити, чому обрано українські лексеми. Не міняти вірш без літературного рев'ю. |
| **1.11** | `muktābhimānī mukto hi baddho baddhābhimāny api … yā matiḥ sā gatir bhavet` | Формула «думка творить твою дійсність» може створити враження твердження про фізичне «матеріалізування» подій, тоді як контекст протиставляє ототожнення себе з вільним і зв'язаним станами. | Звірити значення `abhimāna` та `mati/gati`; зберегти смисл про внутрішню самоідентифікацію, уникаючи непідтвердженої сучасної психологізації. |
| **8.3** | `saktaṃ kāsv api dṛṣṭiṣu` та `asaktaṃ sarvadṛṣṭiṣu` | Португальський посередник і чинний український текст використовують «досвід», але `dṛṣṭi` може означати «погляд», «бачення», «позицію/уявлення» залежно від контексту. | Зіставити словникові значення та контекст сусідніх віршів 8.1–8.4; не проголошувати єдиного рішення до рев'ю. |

**Застереження щодо статті Desai (2025).** Автор обирає **1.11** як предмет дослідження, проте в основному тексті також пов'язує близьку тезу з **1.3**. За санскритським свідком GRETIL 1.3 присвячено відмінності свідомого свідка від елементів, а 1.11 — самоототожненню як вільного або зв'язаного. Тому статтю можна використовувати як приклад рецепції, **але не для нумерації чи лексичного звіряння без незалежної перевірки**.
