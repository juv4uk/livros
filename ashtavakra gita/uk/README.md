# Аштавакра-гіта — український переклад

Цей каталог містить **робочий український переклад** вибраних розділів «Аштавакра-гіти».
Португальські джерела в сусідньому каталозі `chs/` залишено без змін.

## Стан

- Розділ 2 — перекладено вірші 2.1–2.9.
- Розділ 7 — перекладено вірші 7.1–7.5.
- Розділ 8 — перекладено вірші 8.1–8.4.
- Розділ 9 — перекладено вірші 9.1–9.8.
- Розділи 1, 3–6 — **не входять** до цього часткового видання.

Нумерацію віршів збережено відповідно до португальського тексту репозиторію.
Це переклад на основі наявної португальської редакції, а не звірене критичне видання санскритського оригіналу.

## Збирання PDF

У каталозі `ashtavakra gita/uk`:

```sh
pdflatex -interaction=nonstopmode -halt-on-error selected-chapters.tex
pdflatex -interaction=nonstopmode -halt-on-error selected-chapters.tex
```

Потрібні LaTeX із підтримкою української мови, кодування T2A та кириличні шрифти
(наприклад, TeX Live із пакетами `texlive-lang-cyrillic` і `cm-super`).

Файл `selected-chapters.tex` збирає тільки готові українські розділи; він не замінює повний оригінал.
