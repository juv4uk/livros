# Українські переклади

Цей каталог призначений для українських перекладів текстів, що зберігаються в репозиторії. Португальські вихідні файли залишаються незмінними, щоб можна було звіряти зміст і нумерацію.

## Аштавакра-гіта

Перший робочий переклад охоплює звернення Джанаки (1.1) і настанови Аштавакри (1.2–1.20). Збережено позначення віршів та структуру LaTeX. Переклад зроблено з наявного португальського тексту, **не безпосередньо із санскриту**. Він потребує редакторського й термінологічного звіряння.

Для складання PDF (потрібен TeX Live із пакетом texlive-lang-cyrillic або відповідні пакети MiKTeX):

```sh
cd uk
mkdir -p build
pdflatex -interaction=nonstopmode -halt-on-error -output-directory=build ashtavakra-gita.tex
```

## Принципи перекладу

- Зберігати структуру, нумерацію віршів і атрибуцію джерела.
- Уніфікувати ключові терміни: **Свідомість**, **звільнення**, **самопізнання**, **Я**, **самсара**; переглядати їх у контексті.
- Відрізняти переклад від коментарів перекладача, не дописувати думки від імені автора.
- Для сучасних творів перед публікацією перекладу окремо перевіряти права на переклад і поширення. Ліцензія репозиторію сама по собі не доводить, що всі вкладені книги, PDF і переклади мають однаковий правовий статус.
