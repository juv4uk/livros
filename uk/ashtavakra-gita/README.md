# Аштавакра-гіта — українська редакція

Початковий український переклад за наявними **португаломовними файлами**
`ashtavakra gita/chs/` цього репозиторію. Це **не прямий переклад із санскриту**
й не перевірена на відповідність санскритському оригіналу наукова редакція.

## Стан перекладу

- Вступ (вірш 1.1) — перекладено.
- Розділ 1 (вірші 1.2–1.20) — перекладено.
- Розділ 2 (вірші 2.1–2.9) — перекладено.
- Наступні розділи — поки не перекладено.

Збережено оригінальну нумерацію, зокрема відсутність 1.1 у файлі
першого розділу (цей вірш міститься у вступі). Термін «Свідомість»
поки передано з великої літери відповідно до португальського тексту.

## Збірка

Потрібен XeLaTeX, `fontspec`, `polyglossia`, пакет `geometry`
і шрифт **DejaVu Serif**.

```sh
cd uk/ashtavakra-gita
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

## Перевірка перед публікацією

Потрібне звіряння термінів і змісту з авторитетною редакцією санскритського
тексту; особливо слів «Я», «Свідомість», «Єдність», «блаженство», «сансара».
Не приписуйте автоматично цій редакції або використаним перекладам правовий
статус суспільного надбання: його слід перевіряти для кожного джерела окремо.
