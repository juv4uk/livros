# Редакційний словник українського перекладу

**Статус:** чернетка для узгодження термінів. Це не механічний словник підстановок: остаточний варіант визначає контекст, жанр і, за можливості, текст першоджерела.

| Португальське слово або вислів | Робочий український відповідник | Примітка |
| --- | --- | --- |
| consciência | свідомість | Якщо йдеться про здатність усвідомлювати; в окремих контекстах — «усвідомлення» |
| Consciência Una | єдина свідомість | Велику літеру залишати лише там, де вона має змістову функцію |
| autoconhecimento | самопізнання | Не плутати із самосвідомістю |
| autorrealização | самореалізація / осягнення власної природи | У духовному контексті «самореалізація» не завжди означає соціальний успіх |
| libertação | визволення / звільнення | Обирати за контекстом; у межах одного твору прагнути послідовності |
| testemunha | свідок / спостерігач | Для «свідомості-свідка» зазвичай «свідок» |
| desapego | неприв'язаність | Не ототожнювати з байдужістю |
| sofrimento | страждання | Не автоматично замінювати на «біль» |
| despertar | пробудження | Зважати на відмінність від «просвітлення» |
| iluminação espiritual | духовне просвітлення | Не підмінювати словом «освітлення» |
| ser | буття / істота / бути | Розрізняти іменник, дієслово та філософську категорію |
| samsara | сансара | Передавати як усталений термін; за першої згадки можна дати пояснення |

## Редакційні принципи

1. **Точність перед буквальністю.** Не переносити португальський синтаксис дослівно, якщо в українській це спотворює значення.
2. **Поважати джерело.** Якщо португальський текст сам є перекладом, за можливості звіряти з оригінальною мовою та чесно зазначати використану редакцію.
3. **Не втрачати неоднозначності.** Не перетворювати філософське твердження на однозначнішу тезу без підстав.
4. **Зберігати структуру.** Номери віршів, `\\chapter`, `\\section`, примітки, цитати й внутрішні посилання мають залишатися простежуваними.
5. **Вичитувати українську.** Перевіряти милозвучність, відмінювання, лапки «…», довге тире — та уникати невиправданих кальок.
6. **Розмежовувати текст і коментар.** Перекладацькі пояснення позначати окремо від авторського тексту.
7. **Фіксувати рішення.** Якщо термін викликає суперечку, документувати приклад і аргументацію у відповідному PR.

## Критерії готовності розділу

Розділ готовий до редакційного погодження, коли підтверджені права на публікацію, кожен фрагмент звірено з джерелом, пропуски й додавання позначено, терміни узгоджено, а LaTeX (якщо використовується) успішно збирається у PDF.

**Примітка:** робочі відповідники назв у [каталозі](README.md) не є фінальними назвами майбутніх видань.
