# Український переклад «Чиста благодать»

Це **робочий переклад**, а не повне українське видання книжки **Pura Graça** Артура Пауліно.

- Основний LaTeX-файл: `pura graca/uk/chysta-blahodat.tex`.
- Включено прелюдію, повний розділ «Біль» (перший PR) та повний розділ «Пошук» (доповнення).
- Для «Пошуку» кожен переклад збережено окремим файлом у `pura graca/uk/txts/`; імена файлів відповідають португальським оригіналам.
- Потрібні літературна редактура, звіряння з португальським текстом і підтвердження прав на переклад перед публікацією.
- Португальський оригінал не змінено.

Для збирання потрібні **XeLaTeX**, модуль української мови Babel і шрифт **DejaVu Serif**:

```sh
cd "pura graca/uk"
xelatex -interaction=nonstopmode -halt-on-error chysta-blahodat.tex
```

**Редакторський принцип:** зберігати поетичні образи, малі літери та переноси рядків. Статус перекладу не прирівнювати до завершеного видання.
