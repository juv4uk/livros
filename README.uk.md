# Український переклад «Чиста благодать»

Це **чернетковий фрагмент**, а не повне українське видання книжки **Pura Graça** Артура Пауліно.

- Файл: `pura graca/uk/chysta-blahodat.tex`.
- Включено прелюдію, початок частини «біль» та добірку коротких віршів.
- Потрібні літературна редактура, звіряння з португальським текстом і перевірка прав на текст перед публікацією.
- Оригінал не змінено.

Для складання потрібні pdfLaTeX і пакети підтримки української мови та кириличних шрифтів:

```sh
cd "pura graca/uk"
pdflatex -interaction=nonstopmode -halt-on-error chysta-blahodat.tex
```

**Редакторський принцип:** зберігати поетичні образи, малі літери та переноси рядків. Статус перекладу не прирівнювати до завершеного видання.
