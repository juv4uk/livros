# Книжки й переклади / Livros e traduções

Колекція текстів, книжкових макетів і перекладів. Зберігаємо вихідні документи, а українські редакції створюємо окремо, не змінюючи оригіналів.

## Видання

- [«Чиста благодать» / Pura Graça](pura%20graca/uk/README.md) — українською перекладено вступ, прелюдію та перший розділ «Біль»; наступні розділи ще в роботі.
- [Da Perfeição de Ser](da%20perfeicao%20de%20ser/) — португальське видання.
- [O Caminho da Libertação](o%20caminho%20da%20libertacao/) — вихідні матеріали для майбутнього перекладу.
- [Ashtavakra Gita](ashtavakra%20gita/) — джерельні матеріали для майбутнього перекладу.

## Правила перекладу

Українські тексти розміщуємо в окремому підкаталозі `uk/` відповідної книжки; зберігаємо авторство, структуру й початкові файли. Завершені частини перекладу мають бути придатними до збирання з LaTeX, а статус перекладу — чітко вказаним.

**Права:** перед публікацією перекладів сторонніх творів перевіряємо права автора й перекладача. Самої наявності PDF у репозиторії недостатньо, щоб вважати твір вільним для перекладу.
