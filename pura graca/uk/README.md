# «Чиста благодать» — українська редакція

Український переклад книжки **«Pura Graça»** Артура Пауліно (*Arthur Paulino*).

**Стан:** перекладено вступні вірші, прелюдію та весь перший розділ «Біль». Інші розділи поки залишаються португальською в оригінальному каталозі. Цей файл не слід видавати за повний переклад книжки.

## Структура

- `chysta-blahodat.tex` — самостійний LaTeX-макет поточної української редакції.
- `txts/*.tex` — перекладені тексти з назвами файлів, що відповідають оригінальним `../txts/*.tex`.
- Португальський оригінал зберігається без змін.

## Як зібрати PDF

Установіть XeLaTeX, підтримку української мови для Babel і шрифт **DejaVu Serif**. Далі з каталогу `pura graca/uk` виконайте:

```sh
xelatex -interaction=nonstopmode -halt-on-error chysta-blahodat.tex
```

Результат: `chysta-blahodat.pdf`.

## Принципи перекладу

Збережено авторський стиль малих літер, послідовність текстів, авторство та логіку верстки. Зміст перекладаємо природною українською, не додаючи власних філософських пояснень. Кожен наступний розділ слід перекладати окремим невеликим PR та перевіряти компіляцію PDF.

Під час розширення видання додавати нові `\input{txts/...}` у макет лише після завершення відповідних перекладів. Перед поширенням перекладів інших книжок із репозиторію окремо перевіряти права їхніх авторів і перекладачів.
